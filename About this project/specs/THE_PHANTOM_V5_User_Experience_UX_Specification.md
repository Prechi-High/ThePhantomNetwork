# THE PHANTOM V5 User Experience UX Specification

THE PHANTOM V5 - User Experience (UX) Specification
Core Philosophy
THE PHANTOM is experienced as entering a living competitive world, not simply opening an app. Every interaction reinforces: 'My next action makes me more important in this world.'
UX Pillars
Immediate Clarity; Continuous Progression; Living World; One Purpose Per Screen; Emotional Journey (Arrival→Belonging→Growth→Competition→Recognition→Leadership→Legacy); Identity Before Rewards; Zero Friction.
Zero Friction
No dead ends. Context-aware bottom sheets. Exact next actions. Stay in flow. Bottom sheets for temporary tasks. Progressive disclosure. Instant feedback. Three-tap rule.
Navigation
Maximum five tabs: Home, Sessions, World, Creator, Legacy.
Hierarchy
Primary information first, secondary context second, tertiary activity last.
Visual Focus
Each screen has one dominant focal element.
Reward Psychology
Every meaningful action gives visible feedback.
Premium Experience
Clean, spacious, responsive, intentional.
Living Ecosystem
Always show live activity, sessions, rankings, creator content, wars and progression.
Ultimate Rule
Every screen answers: Who am I? How am I progressing? What should I do next? Why should I care right now?
