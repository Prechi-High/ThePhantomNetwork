# THE PHANTOM V5 Design System and User Journey

THE PHANTOM V5 — Design System & Complete User Journey
Design System
Design Philosophy: Premium digital civilization; elegant, alive, prestigious.
Visual Principles: One focal point, generous spacing, motion over decoration, layered depth, living world.
Colors: Background #0B0F14, Surface #131922, Card #1B2230, Divider #2A3447, Legacy Gold #F5B942, Phantom Blue #4C8DFF, Emerald #39D98A, Amber #F5A623, Crimson #E64D5E.
Typography: Manrope (preferred), 8pt spacing grid, rounded components, soft shadows.
Navigation: Max five tabs (Home, Sessions, World, Creator, Legacy).
Motion: Meaningful transitions, breathing UI, counters, promotion animations.
Components: Bottom sheets preferred over page switching; minimal friction.
Emblems: Curated 3D camp/squad emblems; user profile images are custom.
