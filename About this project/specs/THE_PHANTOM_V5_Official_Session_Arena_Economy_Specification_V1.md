# THE PHANTOM V5 Official Session Arena Economy Specification V1

THE PHANTOM V5 — Official Session & Arena Economy Specification (V1)
Official Session
6 official sessions/day (every 4 hours).
20-minute minimum session.
Average spin: 6 seconds.
Each Official Session contains multiple Arenas.
Squads
Maximum 15 members per Squad.
Inactive for 7 days -> automatically removed from Squad.
Squad Masters manage recruitment.
Arena Allocation
Target: 10 Squads per Arena.
Minimum viable Arena: 7 Squads.
If remaining Squads are fewer than 7, redistribute them evenly into existing Arenas.
Example: 53 Squads -> 11/11/11/10/10. Example: 67 Squads -> 10/10/10/10/10/10/7.
